# Dino Empire

An idle dinosaur collecting game in a single self-contained HTML file.

**Play:** https://justplaymygame-glitch.github.io/dino-empire/

- 50 dinosaurs across 5 worlds and 16 rarity tiers
- Egg hatching, levels to 100, ascension and rebirth
- Fusion, daily quests, rotating events, trade post, local leaderboards
- Admin console (open the padlock, password `1234`)

Progress saves in your browser's local storage.
